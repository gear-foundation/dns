# Настройка логирования и мониторинга API

## Обзор

Добавлена система логирования и мониторинга для отслеживания обращений к API сервису. Система включает:

1. **RequestLoggerMiddleware** - логирует все входящие запросы
2. **AnalyticsService** - собирает и анализирует статистику
3. **MonitoringService** - периодический мониторинг и очистка данных
4. **AnalyticsController** - API для просмотра статистики

## Что логируется

### Для каждого запроса:
- IP адрес клиента (с учетом прокси и load balancer)
- User-Agent
- HTTP метод и URL
- Referer
- Время ответа
- Статус код ответа
- Количество запросов от данного IP

### Аналитика:
- Топ активных IP адресов
- Частота запросов по IP
- Уникальные эндпоинты для каждого IP
- Средние времена ответа
- Количество ошибок
- Подозрительная активность (боты, сканеры, DDoS)

## Переменные окружения

Добавьте в ваш `.env` файл:

```env
# Токен для доступа к эндпоинтам аналитики
ANALYTICS_AUTH_TOKEN=your-secret-token-here

# Окружение (для production включается проверка авторизации)
NODE_ENV=production
```

## API эндпоинты для мониторинга

### 1. Общая статистика
```
GET /api/analytics/stats?auth=your-token
```

Возвращает:
- Общее количество запросов
- Количество уникальных IP
- Временную метку

### 2. Топ активных IP
```
GET /api/analytics/top-ips?limit=10&auth=your-token
```

Возвращает топ IP адресов с подробной статистикой.

### 3. Детали по конкретному IP
```
GET /api/analytics/ip-details?ip=1.2.3.4&auth=your-token
```

Возвращает подробную статистику для указанного IP.

### 4. Недавняя активность
```
GET /api/analytics/recent-activity?minutes=60&auth=your-token
```

Возвращает активность за последние N минут.

## Логи в консоли

### Типы логов:

1. **[INCOMING]** - входящий запрос
2. **[RESPONSE]** - ответ на запрос
3. **[HIGH_FREQUENCY]** - высокая частота запросов (>60 req/min)
4. **[SUSPICIOUS_USER_AGENT]** - подозрительный User-Agent
5. **[ENDPOINT_SCANNING]** - сканирование эндпоинтов
6. **[TOP_ACTIVE_IPS]** - топ активных IP (каждые 1000 запросов)
7. **[STATS]** - общая статистика (каждые 15 минут)
8. **[HOURLY_TOP_IPS]** - топ IP за час
9. **[ANOMALY_DETECTION]** - аномальная активность
10. **[DDOS_DETECTION]** - потенциальная DDoS атака

### Примеры логов:

```
[INCOMING] GET /api/dns/contract | IP: 192.168.1.100 | User-Agent: Mozilla/5.0... | Referer: https://example.com | Requests from IP: 1

[RESPONSE] GET /api/dns/contract | Status: 200 | Duration: 45ms | IP: 192.168.1.100

[HIGH_FREQUENCY] IP: 192.168.1.100 made 65 requests in last 5 minutes | Endpoint: /api/dns

[DDOS_DETECTION] Potential DDoS activity detected from 3 IPs:
  - 192.168.1.100: 150 requests in 5 minutes
  - 10.0.0.50: 120 requests in 5 minutes
```

## Автоматическая очистка

Система автоматически очищает старые данные:
- Каждые 6 часов удаляются данные старше 24 часов
- Ограничение на 10,000 запросов в памяти для предотвращения утечек

## Мониторинг производительности

Система отслеживает:
- Время ответа для каждого запроса
- Частоту ошибок по IP
- Аномальную активность
- Потенциальные DDoS атаки

## Установка зависимостей

```bash
npm install @nestjs/schedule
```

## Безопасность

- Эндпоинты аналитики защищены токеном авторизации
- В production режиме обязательна авторизация
- Логи не содержат чувствительных данных
- Автоматическая очистка предотвращает накопление данных

## Использование

1. Установите зависимости: `npm install`
2. Настройте переменные окружения
3. Запустите приложение: `npm run start`
4. Мониторьте логи в консоли
5. Используйте API эндпоинты для детального анализа

## Рекомендации

1. Регулярно проверяйте топ активных IP
2. Обращайте внимание на логи HIGH_FREQUENCY и DDOS_DETECTION
3. Анализируйте User-Agent для выявления ботов
4. Мониторьте время ответа для оптимизации производительности
5. Настройте алерты на основе логов для автоматического уведомления
